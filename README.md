## 🤖 AI 协作工作流

所有 AI 功能采用 **「手动协作」** 模式：你在外部 AI 助手（WorkBuddy）处理 → 复制结果 → 粘贴回工作台解析。

### 典型流程：AI 导入日程任务

1. 拍一张白板或截图
2. 发给 AI 助手："请把图片里的任务整理出来，标注日期和重要程度"
3. AI 返回文字：
```
7月28日：完成项目报告 ⭐
明天：客户电话
下周三：复盘会议
```
4. 工作台 → 日程表 → **🤖 AI导入**
5. 粘贴文本 → 点击「智能解析」
6. 系统自动识别日期（今天/明天/下周X/具体日期）和优先级

### 其他 AI 入口
- **拍照识字**：工作区 → 知识库 → 🤖 拍照识字
- **获取热点**：自媒体 → 热点速报 → 🤖 获取热点
- **AI 推荐**：个人成长 → 副业探索 → 🤖 AI推荐
- **AI 探讨**：个人成长 → 书籍阅读 → 🤖 AI探讨

## 💾 数据管理

- **自动保存**：所有操作即时写入 localStorage
- **建议备份**：每周点顶栏 📥 导出按钮
- **导入备份**：系统 → 设置 → 导入数据
- **清除数据**：系统 → 设置 → 清空（需输入「确认清空」）

## 💡 操作技巧

- 主题切换：顶栏 🌙 按钮
- 移动端：左上 ☰ 展开侧边栏
- 优先级：⭐ 重要 / 📘 普通
- 任务状态：待定/草稿/已发布
- 图表悬停查看数据

1. **早上 9:00** - 打开日程表，检查今日任务
